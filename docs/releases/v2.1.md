# v2.1 — 数据保留与短横版导出修复

版本 `2.1 / 20100`。本版仅处理 #74、#73、#76，不加入新功能；兼容 2.0 项目，保留包名、生产签名与 `android-alpha-renderer-1` 合同。1.x 项目仍保留但不迁移。

- **短横版导出**：区分实际画布高度 `640..6400` 与手动请求高度 `720..3600`。Kotlin、Schema/TypeScript 和测量桥接统一校验，1227×697 不再在回填时被拒绝，也不强制补高到 720。非法、超大尺寸和编码/实际图片尺寸校验继续生效。编码倍率按 Canvas 的向下取整处理；原生解码流在发布文件前显式关闭。
- **封面与编辑历史**：当前项目、undo/redo、导入回滚快照和在途保存以独立所有者保留实际图片。替换、移除后仍可撤销重做；历史裁剪、redo 清空、编辑器关闭后回收不再被需要的图片。回收继续检查 Room 多项目引用；失败/取消的未提交导入释放预留。
- **导入失败与并发编辑**：网络阶段继续允许编辑。应用后的保存失败按 revision 执行局部回滚，只撤回仍属于该导入的值；新的歌词文档、字号、项目名和编辑历史保留并继续保存。新导入等待被取消的旧导入完成回滚，避免旧操作覆盖新结果。
