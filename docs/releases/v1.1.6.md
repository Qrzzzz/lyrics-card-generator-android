# v1.1.6 — 安全依赖与构建流程维护

版本 `1.1.6 / 10106`。对应维护计划 Step 5–6；保持包名、生产签名、保存格式和 `android-alpha-renderer-1` 协议。

- Kotlin Android、Compose compiler 与 serialization 插件统一升级至稳定版 2.4.20，KSP 升至 2.3.12；保留 AGP 8.13.2、Gradle 8.14.4 和 JDK 17 构建目标，显式使用支持 Kotlin 2.4 metadata 的 R8 9.1.29。
- Commons Compress 在宿主 buildscript 中约束至 1.26.0，并将扫描新识别的传递依赖 Commons Lang 升至 3.18.0，扩展已有依赖解析检查，防止旧版本或宿主依赖进入应用／仪器测试配置。
- 合入 #57 的 checkout、setup-java、Gradle Actions 更新，并将 upload-artifact / download-artifact 更新至固定 SHA 的 7.0.1 / 8.0.1。继续使用默认 ZIP 归档、90 天候选保留、原始五附件与签名来源验证。
- 不改变产品交互，不混入 1.1.7 的 React、coroutines 或 serialization runtime 更新。

## 验证与发布

精确 source、CI、默认分支告警和签名候选证据在本版验收记录完成后绑定。PR 检查不代表正式发布完成。

实体设备六项人工操作、跨 API 矩阵、20 次导出、耐久、低内存、TalkBack 与大字体专项本版未执行时保持 **NOT RUN**。历史 v1.1.5 API 30 结果仅作为历史证据，不冒充本版测试。
