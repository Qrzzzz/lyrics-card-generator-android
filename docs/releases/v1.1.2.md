# v1.1.2

本版本集中处理仓库维护与依赖安全：修复构建、测试和 Renderer 工具链中的 Bouncy Castle、Netty、JDOM、jose4j 与 Vitest 告警；恢复有界的每月依赖更新；按改动影响范围执行 CI，同时继续对依赖、构建配置、发布输入和未知路径运行完整质量门。React、React DOM 与类型声明保持在已验证的 19.2 解析树。本轮没有新增产品功能，也不改变 Renderer 协议、生产签名或发布权限。

## 当前发布状态

维护者 Qrzzzz 已在 Xiaomi 2210132C / API 36 上确认 `focused-manual-v1` 六项操作全部通过；实际安装版本为 1.1.2 / 10102，设备 base.apk 哈希与冻结签名候选一致：

签名候选的源码提交、工作流运行、哈希和 artifact attestation 以 [#45](https://github.com/Qrzzzz/lyrics-card-generator-android/issues/45) 中的实际运行记录为准。六项真实确认与设备绑定见 [v1.1.2 验收记录](v1.1.2-acceptance.json)。原始候选 metadata 保留构建时状态，不改写为完整设备矩阵通过。

## 剩余风险

- API 30 上既有的 1×→2× 导出超时尚未由最终候选复核，不能改写为通过。
- [#35](https://github.com/Qrzzzz/lyrics-card-generator-android/issues/35) 仍跟踪 protobuf-java、protobuf-kotlin 与 jsoup 高危告警及其 UTP、instrumentation 和设备验证缺口；原始截止日期仍为 **2026-09-18**。
- 签名候选及同 SHA 托管检查已通过，六项人工确认已完成；未覆盖专项仍按实际披露。

附件中，`.apk` 用于安装，`.aab` 用于应用分发，`mapping.txt` 用于对应版本的崩溃排查；附件校验信息随最终源码提交和工作流运行一并提供，复用同一签名候选的原始字节。
