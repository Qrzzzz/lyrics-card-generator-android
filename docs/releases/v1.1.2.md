# v1.1.2（候选）

本候选集中处理仓库维护与依赖安全：修复构建、测试和 Renderer 工具链中的 Bouncy Castle、Netty、JDOM、jose4j 与 Vitest 告警；恢复有界的每月依赖更新；按改动影响范围执行 CI，同时继续对依赖、构建配置、发布输入和未知路径运行完整质量门。React、React DOM 与类型声明保持在已验证的 19.2 解析树。本轮没有新增产品功能，也不改变 Renderer 协议、生产签名或发布权限。

## 剩余风险

- API 30 上既有的 1×→2× 导出超时尚未由最终候选复核，不能改写为通过。
- [#35](https://github.com/Qrzzzz/lyrics-card-generator-android/issues/35) 仍跟踪 protobuf-java、protobuf-kotlin 与 jsoup 高危告警及其 UTP、instrumentation 和设备验证缺口；原始截止日期仍为 **2026-09-18**。
- 发布仍需从最终不可变提交生成候选，并完成同 SHA 的托管检查、产物证明和上述六项真机确认。

候选完成后，`.apk` 用于安装，`.aab` 用于应用分发，`mapping.txt` 用于对应版本的崩溃排查；附件校验方式将在实际发布记录中随最终源码提交和工作流运行一并给出。
