# v2.4 — 修复依赖安全审计失败

版本 `2.4 / 20400`，以 2.3 为基础发布本次依赖安全修复。沿用 2.x 两段版本号，这是当前版本规则下的下一最小版本。

- fast-uri 的精确 override 从 3.1.6 更新到 3.1.9，解除旧固定版本对安全修复的阻塞。
- source-map-js 从 1.2.1 更新到 1.2.2；Vite 从 8.3.0 更新到 8.3.5。
- Vitest 及配套 @vitest/* 从 4.1.11 更新到 4.1.12，一并修复 moderate 告警。相关构建依赖保持现有大版本。
- 保留 npm 审计的 high/critical 阈值、网络重试规则、包名、生产签名和 `android-alpha-renderer-1` 合同。2.x 项目继续兼容；1.x 项目继续保留但不迁移。

## 原因与验证范围

[原定时 run 40297265489](https://github.com/Qrzzzz/lyrics-card-generator-android/actions/runs/40297265489) 在未变更的主干源码上检出三个 high、两个 moderate 风险包，安全审计退出 1，汇总门禁按规则失败；Android 构建、Renderer、合同与 Unicode JVM 检查均通过。原失败记录保持不变。

依赖修复提交 `71e76c2` 的本地 Node 24.22.1 检查通过：锁定安装、npm 全依赖审计（0 vulnerabilities）、类型检查、101 项 Renderer 测试、生产构建，以及 CI/发布/来源/设备证据合同。依赖安全合同的一个符号链接夹具因 Windows EPERM 跳过，其余通过。该提交的 [Quality Gate 40299960529](https://github.com/Qrzzzz/lyrics-card-generator-android/actions/runs/40299960529) 与 [Dependency Review 40299960575](https://github.com/Qrzzzz/lyrics-card-generator-android/actions/runs/40299960575) 均通过。

2.4 的冻结源码为 `719b6d2a0aaab9edc78ba2b7d1221b91d0958d49`，由 [PR #90](https://github.com/Qrzzzz/lyrics-card-generator-android/pull/90) 合入。同 SHA 主干 [Quality Gate 40305389067](https://github.com/Qrzzzz/lyrics-card-generator-android/actions/runs/40305389067) 和 [Dependency Security 40305388868](https://github.com/Qrzzzz/lyrics-card-generator-android/actions/runs/40305388868) 均 PASS；包含完整 Android JVM/lint/R8/APK/AAB/test APK 打包、Renderer、合同、Unicode JVM 和默认分支依赖图提交。打包 test APK 不代表执行过 instrumentation。

## 仍未覆盖的风险与检查

默认分支宿主构建依赖 Bouncy Castle 的 [告警 #66（critical）](https://github.com/Qrzzzz/lyrics-card-generator-android/security/dependabot/66) 与 [#67（high）](https://github.com/Qrzzzz/lyrics-card-generator-android/security/dependabot/67) 不属于本次 npm 失败，仍未解决。本版不声明全仓漏洞清零，也不更改或豁免 [既有跟踪 #35](https://github.com/Qrzzzz/lyrics-card-generator-android/issues/35) 的严重级别和期限。下一步为验证 BC 1.85 宿主工具链对齐、完整构建及同 SHA 依赖图提交，再核对告警状态。

依赖图刷新时还发现 AndroidTest 的 jsoup 1.23.1 命中 [告警 #73（high）](https://github.com/Qrzzzz/lyrics-card-generator-android/security/dependabot/73)，GHSA-65r4-943x-97jj，首个修复版 1.23.2。本项同样保留在 #35，由 Qrzzzz 继续处理；下一步为独立验证 jsoup 1.23.2、受影响的 accessibility/instrumentation 和完整构建，再核对默认分支告警。当前保留 **1 critical / 2 high** Maven 风险，不把 npm 审计为 0 或本版 CI 通过当作这些告警已解决。

实体设备六项人工操作、本候选 instrumentation、跨 API/WebView 矩阵、20 次导出、低内存、30 分钟耐久、TalkBack 和大字体专项均 NOT RUN。沿用 `focused-manual-v1`：核验同 SHA 主干全量 CI、生产签名和证书连续性、来源、候选哈希及全部附件 attestation，版本绑定授权后公开原始五附件。
