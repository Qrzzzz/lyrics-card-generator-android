- 完善生产签名来源保护：候选绑定主干提交、同提交 CI、环境审批及 GitHub artifact attestation。
- 明确排除 Android 云备份和设备间迁移，并增加编译后资源验证。
- 更新本轮 npm 漏洞依赖，完善持续依赖检测；构建和测试工具链剩余告警继续由 [#35](https://github.com/Qrzzzz/lyrics-card-generator-android/issues/35) 跟踪。
- 补强系统保存、分享、取消恢复等设备测试；发布流程采用冻结候选、真机核心操作确认与托管发布，不再要求每版重跑完整模拟器矩阵。

修复实现见 [PR #36](https://github.com/Qrzzzz/lyrics-card-generator-android/pull/36)，系统保存测试补强见 [PR #37](https://github.com/Qrzzzz/lyrics-card-generator-android/pull/37)，中文路径 wrapper 见 [PR #14](https://github.com/Qrzzzz/lyrics-card-generator-android/pull/14)。发布流程调整不改变本次候选 APK/AAB。

本次由维护者在 Xiaomi 2210132C / API 36 上人工确认核心操作。API 30 专项超时复核及完整兼容性、无障碍和耐久矩阵未执行，继续保留实际覆盖范围与历史失败记录，不宣称这些专项已经通过。

使用 `.apk` 安装应用；`.aab` 用于应用分发，`mapping.txt` 用于版本对应的崩溃排查。附件可用 `SHA256SUMS` 和 GitHub CLI 验证：

```powershell
gh attestation verify <asset> --repo Qrzzzz/lyrics-card-generator-android --signer-workflow Qrzzzz/lyrics-card-generator-android/.github/workflows/release.yml --source-ref refs/heads/main --source-digest 2dacf491985b6e46974e9c11cb3c94745d800f82
```
