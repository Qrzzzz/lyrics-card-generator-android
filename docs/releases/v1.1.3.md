# v1.1.3（开发中，未发布）

本批次按照 `LCG_Android_1.1.2_Agent清理计划.md` 的任务 07/08，检查 API 30 首次 serif 导出，以及编辑、保存、导出与操作恢复链路。版本为 `1.1.3 / 10103`。不修改存储格式、数据库 schema、包名、生产签名身份、`android-alpha-renderer-1` 或 8 秒 spec 超时。

## 修复与回归

- 延迟完成的旧图片保存会覆盖新导出的进度或错误；同一图片较早的保存失败也会覆盖较新的保存成功。三个受控调度回归在原实现均失败。修复为只有当前图片、当前预览代次和最新保存请求可以更新状态，原文件写入继续完成。
- IO 线程已经创建导出文件、但 `withContext` 尚未将对象交回调用方时取消，会丢失临时文件所有权，避开后续清理块。新增确定性取消测试在原创建方式失败；修复在 IO 内记录所有权，交接失败时使用不可取消上下文关闭和删除临时文件，并保留正常交接正例。
- 设备取消失败的直接原因是 `requestExport` 的 finally 先调用切换主线程的 `sendCancel`，返回已取消的调用方时重新抛出取消异常，跳过文件删除。将整个清理块放入不可取消上下文，同时将原恢复回归从 Unconfined Main 改为 Standard Main，以覆盖设备真实存在的返回调度；修改后的测试在旧清理块上失败（8 tests / 1 failure），没有删除或放宽文件、会话及重试断言。
