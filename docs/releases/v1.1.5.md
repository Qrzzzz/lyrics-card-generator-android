# v1.1.5 — 安全依赖与 API 30 回归

版本 `1.1.5 / 10105`。按全量维护计划完成本版 Protobuf、AndroidTest 安全依赖与历史导出风险复核；保留包名、生产签名身份、保存格式和 `android-alpha-renderer-1` 协议。

## 更新

- Protobuf Java/Kotlin 在 bundletool、UTP 和 buildscript 的受影响宿主配置对齐至 3.25.5；不引入应用 runtime。
- Guava AndroidTest 编译与运行时统一至 33.4.8-android，修复 #51 仅升级 compileOnly 与运行时 28.2 严格约束冲突。ATF 保持原 3.1.2，jsoup 测试运行时约束至 1.23.1，覆盖默认分支扫描新识别的 GHSA-pmhh-3w7g-xqp8。
- CI 新增实际依赖解析校验，覆盖十二个 UTP 配置、bundletool、buildscript、测试编译/运行时与应用隔离。
- 自本版起取消强制真机人工验收，继续沿用 Publish Verified Candidate。人工未执行时如实记录 NOT RUN，保留主干同 SHA CI、生产签名、来源、候选哈希和全部附件 attestation 校验。
