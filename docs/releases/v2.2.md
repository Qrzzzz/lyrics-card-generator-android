# v2.2 — 统一尺寸状态与高度模式转换

版本 `2.2 / 20200`，以已发布 2.1 为基础，仅处理 #75、#77。兼容 2.0/2.1 保存项目，保留包名、生产签名和 `android-alpha-renderer-1` 合同；1.x 项目继续保留但不迁移。

- 测量结果保存完整宽高，并绑定不可变 spec、请求 revision 和 Renderer 会话代次；布局、字号变化后，旧响应不能成为当前确认结果。测量不再写回用户的宽高请求或触发自动保存。
- 预览确认结果由导出复用；最终尺寸与解码内存估算共用完整结果，1×、1.4×、2× 按 Canvas 向下取整。尚未测量时明确显示正在确认，恢复页面后重新测量；生成成功后优先展示文件实际尺寸。
- 请求高度独立于自动测量保留。自动转手动时采用明确边界转换：640→720、720→720、3200→3200、4000→3200；调整时显示原因和重新开启自动高度的建议。合法手动请求在自动模式往返后保留，不改动歌词，也不加入自动裁切逻辑。
