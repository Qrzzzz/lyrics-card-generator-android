# v2.0 — 文档与渲染升级

版本 `2.0 / 20000`。桌面来源锁定 `4f2b411c1d9903727ab2680cd727247f751fd6ad`（v6.3.5），保留 Android 六步原生编辑界面和本地保存分享。

**2.0 无法打开 1.x 项目，不提供迁移。旧记录仍保留，不会自动删除。升级前请在旧版导出需要保留的图片，并在 2.0 重新创建项目。**

- LyricDocumentV2 统一段落、歌词单元、原译文配对、稳定 ID 和空行，贯通编辑、撤销重做、Room、本地桥接与 Renderer。
- 横竖布局使用内容实测与自动尺寸；对齐字体预设，新增本地字体导入、中西文混排、字重、斜体和间距控制。
- 移植完整封面取色和空间流光色场，按画布比例生成背景，保留可读性文字阴影，补齐网格、分隔符、Explicit 和独立署名页脚。
- 支持 PNG / WebP / JPG、1× / 1.4× / 2×；预览与导出使用同一测量结果，并校验实际格式、尺寸、MIME 与保存扩展名。
- 新版本采用 2.0、2.1 两段号，versionCode 持续递增。生产包名、签名身份和 `android-alpha-renderer-1` 合同标识保持不变。

## 验证范围

本地 Renderer 87 项、JVM、lint、可安装 debug APK 和发布合同通过。桌面与 Android 同样例竖版均为 1040×640、横版均为 1227×697；浏览器实际编码并重新解码横竖三格式输出。详细差异见 [对齐记录](../ANDROID_2.0_PARITY.md)。

正式发布绑定同一源码的主干完整 CI、生产签名候选、证书、SHA-256 和 GitHub attestation，具体运行及候选哈希见 [本版验收记录](v2.0-acceptance.json)。沿用 focused-manual-v1；原 metadata 的 PROVISIONAL / NOT RUN / finalReady=false 保持原样，发布验证记录单独表达。

六项实体设备人工操作、跨 API / WebView 矩阵、字体选择器与系统分享实机操作、20 次导出、低内存与 30 分钟耐久、TalkBack 和大字体专项均 **NOT RUN**。浏览器与 JVM 检查不替代真机证据。
