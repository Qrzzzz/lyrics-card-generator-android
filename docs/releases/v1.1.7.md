# v1.1.7 — 运行库与 Renderer 维护

版本 `1.1.7 / 10107`，完成维护计划 Step 7–9。包名、生产证书、保存格式和 `android-alpha-renderer-1` 协议保持不变。

- coroutines 与 serialization JSON 运行库更新至稳定版 1.11.0，补充排队导出取消、旧项目保存重读、异常数据与 Native/Renderer 消息兼容回归。
